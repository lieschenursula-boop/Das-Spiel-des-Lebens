# Das Spiel des Lebens

Conways Spiel des Lebens mit unendlicher Welt zum Malen, Zufallsmustern, Weihnachts-Überraschung und einer Bibliothek mit über 700 Figuren.

Website: https://lieschenursula-boop.github.io/Das-Spiel-des-Lebens/
Spielen: https://lieschenursula-boop.github.io/Das-Spiel-des-Lebens/spielen/

Installieren: Den Spielen-Link in Chrome auf dem Handy öffnen → Menü (⋮) → „App installieren“.

Muster und englische Texte: Life Lexicon (Release 29), Stephen Silver und Dave Greene, CC BY-SA 3.0.
